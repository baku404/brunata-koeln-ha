# Portal icon provenance

The integration icons are PNG renditions of the original public portal favicon:
https://online.brunata-koeln.de/logo/brunata_favicon.ico

Retrieved on 2026-10-18 from the favicon link in the Cologne portal HTML. The source ICO contains a single 16 × 16 pixel image. The 256/512 PNG variants use nearest-neighbor scaling to preserve the original pixels and transparency; no new detail or alternate logo was generated. portal-favicon.ico retains the original source file.

The BRUNATA-METRONA mark belongs to its respective rights holder. These third-party brand assets are not covered by this project's MIT license. Their use identifies portal compatibility and does not imply affiliation or endorsement.
