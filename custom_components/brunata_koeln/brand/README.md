# Brand image provenance

The full logo is a resized rendition of the original public Cologne portal image:
https://online.brunata-koeln.de/logo/brunata_logo_desktop.png

Retrieved on 2026-10-18. The source is a transparent 1024 x 449 PNG and matches the reference supplied by the maintainer. The full wordmark is preserved in logo.png (724 x 128) and logo@2x.png (1448 x 256).

The square icon was prepared with OpenAI ImageGen using that source as a visual reference, requesting only the blue/cyan symbol, transparent background, preserved proportions and padding. It is a generated adaptation, not an official high-resolution master. Its release variants are icon.png (256 x 256) and icon@2x.png (512 x 512). The former low-resolution portal-favicon.ico is retained only as a source reference.

These files are shipped in the integration's brand/ directory for Home Assistant 2026.3 and later. See the [Home Assistant branding documentation](https://contributors.home-assistant.io/core/integrations/brands/).
